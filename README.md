# Prolific HRMS Portal

A functional browser-based HRMS portal for **Prolific Business and Consultant**.

## Run locally

1. Clone or download this repository.
2. Open `index.html` in Chrome or Edge.
3. No Node.js, database, or build step is required for the demo.

## Modules

Dashboard, My Profile, Employee Directory, Attendance & Timesheet, Leave Management, Payroll, Performance, Training & Development, Documents, HR Helpdesk, Company Policies, Holiday Calendar, Announcements, and Admin Settings.

## Demo features

- Responsive UI
- Module navigation
- Leave application with browser local storage
- Attendance clock-in/out demo
- Employee details
- Payroll/payslip actions
- HR request flow
- Profile editing entry point

## Production roadmap

Add secure authentication/SSO, RBAC, backend APIs, database, audit logging, payroll integrations, document storage, email notifications, approval workflows, and real attendance/leave rules.
